# F50 刷机资源备份

F50 随身 WiFi 刷机/插件资源集合（2026-11-08 原版资源）。

## 内容
- `CloudFlare_Tunnel插件.js` — Cloudflare Tunnel 插件（内网穿透）
- `OpenList插件.js` — OpenList 插件
- `一键串改许可插件【...】.js` — 支持 F50 / U30 / Pro / V50 / 畅行 / 远航 等系列
- `F50转网口守护_v1.5.1.zip` — 转 RJ45 网口守护（Magisk/KernelSU 模块）
- `F50重启修复(硬复位)_v1.1.zip` — 硬复位重启修复模块

## 注意
- `CloudFlare_Tunnel插件.js` 里的内置 token 已移除，使用时请在插件界面粘贴自己的 tunnel token。
- 请勿把带 token 的版本传回本仓库；若 token 曾泄露，建议在 Cloudflare 控制台轮换或删除对应隧道。
